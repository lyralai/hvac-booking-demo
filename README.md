# HVAC AI Booking Assistant — Demo

Live demo of an AI-powered booking assistant for HVAC companies.

Built for Vancouver, WA / Portland metro area.

## View Demo
Open [index.html](https://lyralai.github.io/hvac-booking-demo/) in your browser.

## What It Does
- Captures leads 24/7 (even after hours)
- Books appointments automatically
- Answers FAQs (pricing, hours, services)
- Tracks revenue recovered
- Sends lead data to dispatch

## Tech
- HTML/CSS/JS (no dependencies)
- Can be connected to n8n + OpenAI for full AI responses
- Deployable on any website as a chat widget
